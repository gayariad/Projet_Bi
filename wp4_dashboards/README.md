# WP4 : tableaux de bord Power BI

Le projet Power BI est enregistré ici au format **.pbip** (Fichier > Enregistrer sous > Projet Power BI),
qui se versionne bien avec git. Pas de `.pbix` (binaire, ignoré par `.gitignore`).

Source de données : connecteur PostgreSQL sur le schéma `entrepot`, compte `lecture`
(voir `docs/connexion.md`). Les identifiants restent dans Power BI Desktop, jamais dans le projet.
